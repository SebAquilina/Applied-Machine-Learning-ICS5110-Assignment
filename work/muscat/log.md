## 26 November 2026 · Cleaning for machine learning

**Contributor and status.** Matthias asked Codex to clean the data for the planned techniques and save it in his member folder. This is a working member dataset for team review. Q51 is agreed. **Outcome and rationale.** Removed the 516 respondents whose Q51 answer cannot supply a training label. Both target definitions retain 96,704 people across 66 samples in original record order. For the proposed “any shortage” target, 29,932 are positive and 66,772 negative. The narrower “sometimes or often” target moves exactly the 15,041 “rarely” responses to the negative class. Only the outcome changes between versions.

**Inputs.** Codex encoded age, education, relative household income, financial satisfaction and health using their recorded numeric or ordered scales. For each, a fixed zero plus a missing flag represents a skipped answer. This preserves observed education zero and keeps the file usable with all four proposed classifiers. The fixed placeholder adds an artificial value, so the matching flag must travel with the value. Using an ordered score also assumes equally sized steps in a linear model unless the member chooses a different encoding. Employment uses seven binary indicators with full-time as the reference and a separate missing category. This avoids treating employment categories as a ranking. A complete-case filter would discard 5,107 labelled respondents on the six primary questions. A median imputation could be compared later if fitted within training folds.

**Scope and leakage checks.** The 18 baseline inputs carry the `x_` prefix. Q54 and its missing flag are optional because they concern hardship during the same period as Q51. Original source position, sample, survey year and both weights are retained as metadata for later split alignment and evaluation. Original Q51 values, alternative targets, respondent identifiers and metadata are excluded from baseline predictors. The clean uses fixed codebook categories and requires no fitting, random seed or train/test split.

The alternate target produced identical predictors, metadata and row order. The lead checked the full baseline matrix (96,704 × 18) and expanded matrix with Q54 (96,704 × 20) using scikit-learn's numeric, finite input and binary-target validation. The finished CSV contains 26 columns and zero empty cells. All 4,869 observed education zeros remain distinct from 980 missing education entries. Both positive survey weights were preserved. A GPT-6.2 Sol agent independently compared all 26 saved fields with the original source using Python's CSV reader and found zero discrepancies, omissions or extra rows. Of all labelled rows, 5,359 have at least one missing input when Q54 is included. The cleaned CSV's SHA-256 is `d1ac155065ce09e51dd20c102fa7e7bf5d33f5e1fb6b4e6758637085585d9c5e`.
